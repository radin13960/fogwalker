# ۰۷ — چک‌لیست کامل تست (فاز ۵)

## الف) خودکار
- `Test Runner > EditMode > Run All` → سبز همه (Save/Settings/State/WeaponMath/Objectives/Unlock).
- `Test Runner > PlayMode > Run All` → سبز همه (Health/Pool/Hitbox/Explosion).

## ب) سناریوهای PlayMode دستی (دقیقاً همین‌ترتیب)
1. **شروع جدید:** Bootstrap → منو → «شروع بازی جدید» → «عادی» → بارگذاری Level1 + هدف اول دیده شود.
2. **کنترل:** حرکت/دویدن/خمیدن/پرش؛ دوربین به دیوار نمی‌خورد (نزدیک دیوار بایستید و بچرخانید، دوربین جمع می‌شود نه عبور).
3. **تیراندازی:** Pistol تك‌آتش؛ AR خودکار با نگه‌داشتن؛ Recoil به‌چشم می‌آید و برمی‌گردد؛ شلیک از پشت دیوار صفر (دوربین به پشت دیوار نزدیک شود/).
4. **خالی+Reload:** کلیک روی خشاب خالی = کلیک خشاب خالی + خودکار Reload؛ Reload حین Pause متوقف و بعداً ادامه می‌یابد؛ مهمات منفی نمی‌شود.
5. **تعویض سلاح:** تاخیر واقعی (۰.۳–۰.۵ث) + مجدد به‌سرعت نمی‌توان سلاح را قطع کرد.
6. **شاتگان/DMR/SMG:** Pickup در مسیر فرعی؛ تفاوت پراکندگی/آسیب/زوم محسوس.
7. **نارنجک:** کم شدن شمارنده، انفجار بعد از فیوز، آسیب ناحیه با Falloff (نزدیک‌تر = بیشتر)، هپتیک/Shake، صدای بلند دشمنان را جلب می‌کند.
8. **کاور:** نزدیک دیوار Q → Snap، حرکت چپ/راست فقط روی امتداد کاور، Aim از بالای کاور، عقب/Q → خروج. دشمن پشت کاور آسیب نمی‌بیند؛ Peek بالای کاور دیده‌شونده است.
9. **AI Rifleman:** به کاور می‌رود؛ برست‌های محدود؛ عقب‌نشینی پایین‌جان.
10. **AI Rusher:** نزدیک می‌شود و Flank می‌زند؛ بدون کاور.
11. **AI Heavy:** کند، سخت، برست بلندتر (مرحله ۲ و ۳).
12. **گم‌کردن بازیکن:** پشت مانع بروید → دشمن به آخرین نقطه می‌رود → Search → بازگشت به Patrol.
13. **شنوایی:** شلیک از دور → مشاهده حالت Suspicious/Alert در دشمن (Debug: لاگ FSM با WithLogging(true)).
14. **Headshot:** نشانه‌گیری سر (گوی سبز بالا) → آسیب دوبرابر + HitMarker.
15. **Pickupها:** جعبه مهمات (مقیاس با سختی)، کیت (بدون تجاوز از ۱۰۰)، نارنجک، سلاح‌ها.
16. **غیرنظامی مرحله ۱:** E تعامل → کامل شدن obj4 + موج g3.
17. **چک‌پوینت:** عبور = Toast «چک‌پوینت ذخیره شد» → مرگ → «ادامه از چک‌پوینت» → در همان نقطه اسپاون + اهداف کامل‌شده حفظ.
18. **مرگ:** شکست → هر ۳ دکمه کار می‌کند (هیچ Soft Lock). «شروع مجدد مرحله» چک‌پوینت را پاک می‌کند.
19. **پایان مرحله ۱:** صفحه آمار (زمان/دقت/تلفات/اهداف) + «مرحله جدید باز شد» → در منو، Level2 باز است.
20. **مداومة Save:** بستن بازی وسط مرحله → «ادامه بازی» فعال و از آخرین چک‌پوینت.
21. **سختی:** آسان = آسیب کمتر دشمن + منابع بیشتر؛ سخت = دقت بالاتر + منابع کمتر (بدون رفتار نامنصفانه — اسپاون از پشت سر نزدیک وجود ندارد).
22. **Pause:** timeScale=0 (صدای بازی قطع می‌شود، UI زنده است)، تنظیمات داخل Pause کار می‌کند، Resume امن.
23. **چرخش دستگاه:** فقط Landscape؛ گارد SafeArea روی ناچ.
24. **حالت هواپیما (آفلاین):** اجرای کامل بدون خطای شبکه.
25. **رجوع به منو از Pause:** منوی اصلی بدون کرش؛ ورود مجدد به مرحله تازه.

## ج) عملکرد (روی دستگاه واقعی — پروفایل‌ها)
| معیار | هدف | ابزار |
|---|---|---|
| FPS میان‌رده (Balanced/Performance) | ≥45 | Profiler/Overlays |
| FPS پرچمدار (High) | ۶۰ پایدار | Profiler |
| GC Alloc هر فریم در نبرد | ~0 (غیر از رشته‌های نادر) | Profiler CPU |
| GC Spike هنگام Spawn موج | ندارد (Pool) | Profiler |
| Draw Calls مرحله | < ~150 (با Batching) | Frame Debugger |
| GC حافظه پایدار پس از ۱۵ دقیقه | بدون روند صعودی (Leak=0) | Profiler Memory |
| زمان بارگذاری مرحله | < ۱۰s میان‌رده | SceneLoader لاگ |
| دما بعد ۱۵ دقیقه | افت محسوس راندمان ندارد | Adaptive اختیاری روشن |

> **تست Adaptive:** `settings.auto_quality` را روشن کنید؛ ۱۵ ثانیه درگیری سنگین → Render Scale یک پله پایین می‌آید و در لاگ توسعه ثبت می‌شود؛ در سکون به‌آرامی برمی‌گردد.
