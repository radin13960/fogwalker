# مه‌نورد (FogWalker) — نسخه ۱٫۰

شوتر سوم‌شخص **آفلاین** برای اندروید، ساخته‌شده با **Unity 6 LTS + URP** در یک تهرانِ **کاملاً تخیلی** (بدون هیچ شخصیت، گروه، سازمان یا رویداد واقعی). ریشه‌ی فضای نام کد: `FogWalker.*`

> شناسه‌ی پکت: `com.mehnordstudio.fogwalker` — شرکت: `Mehnord Studio` — محصول: `FogWalker`

---

## ۱. وضعیت تحویل (همه فازها کامل ✅)

| فاز | عنوان | وضعیت |
|------|------|--------|
| ۱ | زیرساخت: بوت‌استرپ، ذخیره، تنظیمات، کیفیت، ورودی، محلی‌سازی | ✅ |
| ۲ | گیم‌پلی: بازیکن، دوربین، پوشش (Cover)، ۵ سلاح + نارنجک، تعامل | ✅ |
| ۳ | هوش مصنوعی: FSM کامل، درک دید/شنید، ۳ کهن‌الگو، مدرسه‌ی کاور | ✅ |
| ۴ | مأموریت‌ها، اهداف، چک‌پوینت، اسپاون، موزیک/صدا، Pooling | ✅ |
| ۵ | HUD کامل + کنترل لمسی + منوها + ۳ مرحله‌ی کامل + تست‌ها + مستندات | ✅ |

**مشخصات کلیدی مطابق بریف:**

- 🔌 کاملاً آفلاین — بدون لاگین، سرور، تبلیغات، آنالیتیکس آنلاین، چندنفره. `Internet Access: Not Required`
- 📱 فقط افقی (Landscape)، IL2CPP + ARM64، Min API 29، Vulkan با fallback به GLES3
- 🖋 رابط کاربری فارسی راست‌به‌چپ (با سازوکار آماده برای افزودن زبان انگلیسی)
- 📦 داده‌محور با ScriptableObject (سلاح، کهن‌الگوی دشمن، مأموریت، کیفیت، سختی، منابع صوتی)
- ⚔️ پنج سلاح (تپانچه، تفنگ تهاجمی، مسلسل سبک، شاتگان، نشانه‌زن نیمه‌خودکار) + نارنجک محدود
- 🤖 FSM دشمن با ۱۲ وضعیت + ۳ کهن‌الگو (تفنگ‌دار / یورش‌بر / سنگین) — بدون «تقلب» در سختی‌ها
- 🎯 ۳ مرحله‌ی کامل: «بلوار خاموش»، «بازارچه متروک»، «پل مه‌آلود»
- 🎚 ۳ پروفایل کیفیت (Performance / Balanced / High) + کیفیت تطبیقی اختیاری (هدف 45–60 فریم در گوشی میان‌رده)
- 💾 ذخیره‌ی JSON با نسخه‌ی طرح، checksum SHA256، نسخه‌ی پشتیبان و قرنطینه‌ی فایل خراب
- ✅ تست‌های EditMode + PlayMode + چک‌لیست دستی کامل

## ۲. شروع سریع (۶ قدم تا اجرای بازی)

> ❗ **نکته‌ی مهم و صادقانه:** فایل APK نهایی **باید روی سیستم شما** با Unity ساخته شود — این محیط فایل کد و پروژه را تحویل می‌دهد. مسیر ساخت APK فقط دو کلیک است (قدم ۵).

| قدم | کار |
|------|------|
| ۱ | Unity Hub را باز کنید و **Unity 6000.0 LTS** یا جدیدتر (ماژول Android Build Support + OpenJDK/SDK/NDK) را نصب کنید. |
| ۲ | پوشه‌ی این پروژه (`FogWalkerTPS`) را به‌عنوان پروژه باز کنید؛ Unity بسته‌ها را خودش حل می‌کند. |
| ۳ | *(اختیاری ولی توصیه‌شده)* یک فونت فارسی `.ttf` (مثل Vazirmatn) در `Assets/_Project/Art/UI/Fonts/` بگذارید. |
| ۴ | منو: **`FogWalker > Setup > 0 - 🚀 ساخت کامل پروژه (همه مراحل یک‌جا)`** — همه‌چیز (تنظیمات، لایه‌ها، داده‌ها، پری‌فب‌ها، ۵ صحنه + نومش) به‌صورت خودکار ساخته می‌شود. |
| ۵ | منو: **`FogWalker > Build > APK توسعه (Development)`** ⬅ خروجی: `Build/Android/FogWalker.apk` — برای انتشار نهایی: `AAB انتشار (Release)` |
| ۶ | در ادیتور: صحنه‌ی `Bootstrap` را باز و Play کنید؛ روی گوشی: APK را نصب کنید. 🎮 |

راهنمای کامل و عیب‌یابی: **`Docs/05-Build-And-Play.md`**

### ساخت از خط فرمان (بدون باز کردن ادیتور)

```bash
export UNITY_EXE="/opt/unity/Editor/Unity"   # مسیر یونیتی شما
bash tools/build_android.sh apk              # یا aab
# خروجی: Build/Android/FogWalker.apk
```
در ویندوز: `tools\build_android.bat apk`

## ۳. ساختار پوشه‌ها

```
FogWalkerTPS/
├─ Assets/_Project/
│  ├─ Scripts/          # همه کدهای Runtime (namespace: FogWalker.*)
│  │  ├─ Core/          # بوت‌استرپ، ماشین وضعیت بازی، Service Locator، لایه‌ها، لودر صحنه
│  │  ├─ Save/          # مدل ذخیره + موتور JSON/checksum/backup
│  │  ├─ Settings/      # مدیر تنظیمات (صدا، حساسیت، کیفیت، دست‌چپ…)
│  │  ├─ Optimization/  # پروفایل کیفیت URP، PoolManager، کیفیت تطبیقی
│  │  ├─ Controls/      # InputManager + GameInput.inputactions
│  │  ├─ Localization/  # جدول کلید-مقدار، LocalizedText، Rhsaper فارسی
│  │  ├─ Gameplay/      # بازیکن، دوربین، کاور، سلاح/نارنجک، تعامل، AI، مأموریت/چک‌پوینت/اسپاون
│  │  ├─ Audio/         # AudioManager + کتابخانه‌ی SFX/Music (کلیدمحور)
│  │  └─ UI/            # HUD، کنترل‌های لمسی، منوی اصلی/تنظیمات/انتخاب مرحله/جریان بازی
│  ├─ Editor/           # SetupFactory (ساخت خودکار همه‌چیز) + BuildScript (APK/AAB)
│  ├─ Settings/Input/   # GameInput.inputactions
│  └─ Tests/            # EditMode + PlayMode (asmdef جداگانه)
├─ Packages/manifest.json   # URP 17، InputSystem، Cinemachine، AI Navigation…
├─ Docs/               # ۷ سند فنی راهنما (فارسی)
├─ tools/              # اسکریپت ساخت APK/AAB از ترمینال
└─ Build/Android/      # خروجی APK/AAB (بعد از اولین بیلد ساخته می‌شود)
```

> ⚙️ پوشه‌های `Library/` و `ProjectSettings/` وقتی یونیتی پروژه را باز کند ساخته می‌شوند؛ تنظیمات Player پروژه از طریق منوی Setup اعمال می‌شود (مرحله‌ی ۴ شروع سریع).

## ۴. نقشه‌ی سیستم‌ها (چطور به هم وصل‌اند)

| سیستم | کلاس اصلی | نکته |
|------|-----------|------|
| بوت‌استرپ | `GameBootstrapper` | ثبت سرویس‌ها از صحنه‌ی Bootstrap؛ بدون تکرار ثبت |
| وضعیت بازی | `GameStateManager` | ۸ وضعیت + جدول گذار مجاز؛ timeScale و گیت ورودی |
| ذخیره | `SaveSystem` | `persistentDataPath/save.json` + `.bak` + قرنطینه |
| ورودی | `InputManager` + `GameplayInputSource` | کیبورد/گیم‌پد + نوشتن از UI لمسی |
| سلاح | `WeaponController` + `WeaponMath` | Hitscan از مرکز دوربین + اعتبارسنجی muzzle |
| کاور | `CoverController` + `CoverService` | اشتراکی بین بازیکن و AI |
| AI | `EnemyBrain` (FSM) | درک: `EnemyPerception`، تیراندازی: `EnemyCombat`، حرکت: `EnemyMotor` |
| مأموریت | `MissionManager` + `ObjectiveTracker` | اهداف متوالی: رسیدن/نابودی/جمع‌آوری/تعامل/دفاع |
| صدا | `AudioManager` | کلید SFX + حالت موزیک؛ null-safe بدون Mixer |
| رابط | `UIManager` / `HUDController` / `TouchControls` | فارسی، لمسی، دست‌چپ، شامل SafeArea |

## ۵. چطور چیز جدید اضافه کنم؟ (Data-Driven)

### ➕ افزودن سلاح جدید
1. پروژه را باز کنید؛ راست‌کلیک در Project: `Create > FogWalker > Weapons > Weapon Data`
2. فیلدها (دمیج، rpm، مگزین، falloff، اسپرد، fov زوم…) را پر کنید و کلید محلی‌سازی `weapon.*` را در جدول محلی‌سازی ثبت کنید (متد `BuildLocTableFa` در `ProjectSetupUtility.cs` یا از پنجره‌ی SO).
3. سلاح را به `WeaponInventory` بازیکن (پری‌فب Player) اضافه کنید و ترتیب آن را تنظیم کنید.
منطق هیچ‌کجا هاردکد نشده — رفتار تازه فقط از روی داده خوانده می‌شود.

### ➕ افزودن دشمن جدید
1. `Create > FogWalker > AI > Enemy Archetype` و مقادیر HP/سرعت/دقت/تمایل کاور یا یورش را تنظیم کنید.
2. پری‌فب `Enemy` را کپی کنید، archetype جدید را به `EnemyBrain` نسبت دهید.
3. در یک `SpawnZone` مرحله، پری‌فب جدید را جایگزین کنید — تمام.

### ➕ ساخت مرحله‌ی چهارم
1. بهترین مسیر: الگوی `LevelBlueprint` در `SetupFactory.Levels.cs` را نگاه کنید و یک متد مشابه `BuildLevelN()` بنویسید (تعریف خیابان/کاور/انکر/اسپاون‌زون/چک‌پوینت/هدف‌ها به‌صورت کد).
2. `MissionDataSO` جدید بسازید (`Create > FogWalker > Missions`) و اهداف را لیست کنید.
3. صحنه را با `Setup > 5` یا دستی به Build Settings اضافه کنید؛ شناسه‌ی مرحله (level id) جدید در `SceneCatalog` + جدول بازشو (`ProgressUnlocker`) ثبت شود.
4. NavMesh را در همان لحظه‌ی ساخت صحنه بپزید (فکتوری خودش این کار را می‌کند).

### ➕ افزودن زبان انگلیسی
`LocalizationManager` دوزبانه طراحی شده: یک `LocalizationTableSO` جدید با همان کلیدها و متن انگلیسی بسازید، کد را روی `useBuiltInRtlFix=false` برای انگلیسی تنظیم کنید و سوییچ زبان را در `SettingsManager` فعال کنید (کلید `settings.language`).

## ۷. محدودیت‌های شناخته‌شده (شفاف و صادقانه)

1. **آرت واقعی وجود ندارد** — همه‌چیز با placeholder استاندارد (کپسول/مکعب/اسپرایت) ساخته شده؛ معماری برای جایگزینی کامل آماده است.
2. **کلیپ صوتی ضبط نشده** — کتابخانه‌ی SFX/Music با کلیدهای کامل ساخته می‌شود؛ کافیست فایل‌های صوتی را در SOها بندازید. AudioMixer هم با ۱ دقیقه طبق `Docs/03` ساخته می‌شود (مدیر تنظیمات بدون آن خراب نمی‌شود).
3. **فونت فارسی TTF باید خودتان اضافه کنید** (مسیر بالا) — فکتوری هنگام اجرای دوباره، فونت TMP را خودکار می‌سازد. شکل‌دهی فارسی builtin ساده است (لیگاچر «لا» و تشکیل را پوشش نمی‌دهد؛ برای کیفیت بالاتر: RTLTMPro).
4. **انیمیشن/Animator** فقط پارامترهای سیف (SafeAnim) دریافت می‌کند؛ کنترلر انیمیشن واقعی بعداً اضافه می‌شود.
5. **ادامه‌ی چک‌پوینت** دشمنان زنده را ریست نمی‌کند (تعادل پیچیدگی/ثبات — در Docs 06 شرح داده شده).
